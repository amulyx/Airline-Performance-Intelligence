## 📌 Project Overview

Airline Performance Intelligence is a data analytics and machine learning project designed to analyze airline performance and predict flight delay risks. The project combines Power BI dashboards with AI-based predictions to provide clear operational insights.

## 🎯 Objectives

* Analyze airline and flight performance.
* Identify patterns in flight delays.
* Predict the probability of flight delays using Machine Learning.
* Present insights through an interactive Power BI dashboard.

## 📊 Technologies Used

* **Python**
* **Pandas**
* **Scikit-learn**
* **Random Forest**
* **Power BI**
* **Microsoft Excel**
* **Jupyter Notebook / Google Colab**

## 🤖 Machine Learning

A Random Forest classification model was developed to predict flight delay risk using factors such as airline, origin, destination, distance, available seats, passengers, and scheduled duration.

The model generates a **Delay Probability** and categorizes flights into **High Risk** and **Low Risk**.

## 📈 Power BI Dashboard

The dashboard provides:

* Airline performance analysis
* Flight statistics
* AI-based delay risk analysis
* Average delay probability
* Flight-level AI predictions
